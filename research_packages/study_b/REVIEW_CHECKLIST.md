# 研究B离线研究包核查清单

本清单用于内部核查。它记录的是内部Agent多视角审查，不构成专家审查、内容效度验证、构念效度验证或测量等值性结论。

## 研究设计一致性
- [ ] 96 条材料全部进入 `material_matrix.csv`。
- [ ] `condition_id` C0—C5 与 `condition_matrix.csv` 的 D/U 定义一致。
- [ ] 八个场景、两个方向在材料矩阵中完整出现。
- [ ] P1—P6 与条件定义一致（P1=C1−C0，P2=C2−C0，P3=C3−C2，P4=C4−C2，P5=C5−C2，P6=C5−C4）。

## 数据契约与可复现性
- [ ] `build_study_b_protocol_package.py --check` 在相同仓库状态下一致。
- [ ] `asset_hashes.json` 覆盖材料、题项、评分规范、分析计划、示例数据与关键脚本。
- [ ] `scoring_matrix_template.csv` 为 192 行，每条材料对应两个评判槽位。
- [ ] 外部导入 Schema 拒绝缺失题项、未知题项、越界值、重复键、NaN 与 Infinity。

## 公开叙事可理解性
- [ ] 研究B页面清楚说明当前研究范围（材料、测量、分析计划、确定性示例与离线结果导入）。
- [ ] README 与研究文档使用同一表述。
- [ ] 四个主要评价维度（IN/GO/MSI/IC）与题项映射一致；PA5、PA8 保持补充评分位置。

## 误用与误读风险
- [ ] 示例数据标记为分析界面示例，不会被误读为正式结果。
- [ ] 模型 ID 仅作为协议元数据，不据此发起调用。
- [ ] 页面不再承诺正式模型 API 评分。
