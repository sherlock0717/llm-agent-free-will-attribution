# 研究A：身份与决策过程归因

## 一句话说明

研究A观察语言模型在阅读行为材料后，如何根据行动者身份和决策过程写法，对自主性、意图、自由选择、心智与责任作出判断。

## 数据结构

六种过程条件与AI／人类两种身份形成12个实验组合，每个组合包含30次DeepSeek模型问卷评分，共360条记录。记录分布在八个场景中，汇总后形成96个场景×身份×过程条件单元，每个单元约3—4条响应。

## 主要结果

- **过程写法**：在1—7分量尺上，包含理由、反思、反馈与后续行动的高结构过程写法，与只包含较长背景和最终选择的写法相比，能动性评分平均高约1.263分；16/16个场景×身份配对单元同方向。
- **身份标签**：在1—7分量尺上，人类标签下的自由意志归因平均比AI标签高约0.760分；48/48个场景×过程条件配对单元同方向。
- **场景变化**：总体方向在留一场景分析中保持，但差异幅度依赖具体任务。

过程比较对应两种成套写法的整体差异。文本长度与过程条件共同变化，现有数据不能可靠分离两者的独立作用。

## 六种过程条件

1. 直接选择；
2. 长文本直接选择；
3. 列出可选方案；
4. 简洁理由权衡；
5. 完整理由权衡；
6. 反思与反馈修正。

## 为什么有实践价值

研究A说明，评价者可能把“表达得更像有过程”与“行动者更自主、更有意图”联系起来。对模型与Agent评测而言，这要求分别检查最终结果、可验证过程和主体归因；对产品而言，则需要测试身份名称和解释方式是否改变用户信任、覆盖行为与责任判断。
