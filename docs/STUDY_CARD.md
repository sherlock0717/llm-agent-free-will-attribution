# 研究A：身份与决策过程归因基线

研究A是身份与决策过程归因的探索性基线，属于“LLM行动者归因评测”研究计划。它与研究B共享方法基础设施，并分别保存各自的数据、题项和分析结果。

## 研究对象

研究A观察语言模型如何评价一个行动者。材料控制行动者身份和决策过程表述，模型随后对行动控制、理由响应、选择自主性、体验性、感知智能和责任等内容评分。

研究问题是：

> 当最终决定相同或接近时，理由比较、反思修正和身份标签会怎样改变模型的归因判断？

## 分析单位

一条记录对应模型对一份条件化材料给出的评分响应。记录中的“参与者编号”仅用于运行和数据组织，指代模型响应而非人类被试。

## 输入设计

研究A任务交叉组合：

- 八个决策情境；
- 六种决策过程表述；
- AI 决策者与人类决策者两种身份标签；
- 多个归因题项及相应评分范围。

过程条件覆盖直接给出选择、增加背景长度、列出候选方案、比较理由以及根据反馈修正行动等文本线索。

## 输出指标

研究A题项组织为以下几类：

- **能动性**：行动控制、目标维持、理由响应和行为修正；
- **选择自主性与自由意志归因**：选择所有权、替代可能性和外部推动；
- **体验性**：模型是否把行动者看作具有感受能力；
- **感知智能**：理解、逻辑和判断质量；
- **责任相关判断**：结果责任、道德评价和过程解释责任；
- **过程检查**：材料是否呈现候选方案、理由比较与反馈修正。

题项根据既有理论和测量构念进行情境化编写。原研究的信度、效度和因素结构需在本研究语境下另行验证，详细来源见 [`research_and_measurement_sources.md`](research_and_measurement_sources.md) 与 [`scale_source_mapping.md`](scale_source_mapping.md)。

## 数据状态

已有公开结果来自 DeepSeek API 对研究A材料的评分输出。仓库保留聚合数据、分析代码、统计产物和图表；该次运行没有保存完整的模型服务端快照、逐请求 Prompt 快照、token、费用和精确时间信息，因此无法逐请求还原。

确定性 `mock` 数据用于验证任务配置、解析、校验、计分、恢复和产物生成，仅服务于流程检查。

## 结果的使用方式

研究A已有结果适合回答：

- 模型是否会对不同过程表述给出系统性不同的评分；
- 哪些归因维度对身份标签更敏感；
- 某些差异能否由文本长度或感知智能解释；
- 哪些情境和条件容易产生不稳定或相互矛盾的判断。

这些结果描述模型在研究A材料下的归因反应，适用于该研究的探索性比较，作为研究A自身的证据保存，不作为研究B的实证证据。

## 已知方法问题

后续研究需要优先处理：

1. 部分过程条件同时改变理由质量、信息密度、道德合理性和修正能力，后续需要拆分；
2. 能动性、自主性和自由意志题项之间存在语义重叠，后续需要区分；
3. 同一模型对相似材料的重复调用应按模型响应处理，后续需要区分于独立人类样本；
4. 现有数据来自单一模型，跨模型和跨 Prompt 改写的稳健性列为下一步检验；
5. 该次运行的逐请求来源信息有待补全。

因此，研究A结果以描述性比较和关联性诊断为主。新的模型运行应保存完整配置、模型标识、Prompt、原始响应、错误记录和运行清单，并使用按场景或改写版本聚类的统计方法。

## 复现范围

研究A可以复现：

- 依赖安装与测试；
- 任务配置加载；
- 确定性模拟运行；
- 响应解析、校验和计分；
- 分析产物与展示页数据生成；
- 运行文件的哈希和清单记录。

已有 DeepSeek 输出可用于复核聚合结果，但不能逐请求复现。
