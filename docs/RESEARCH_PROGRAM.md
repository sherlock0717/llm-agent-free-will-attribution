# LLM行动者归因评测：研究计划

## 1. 总体研究问题

本项目研究一个问题：同一个决定被写成不同的身份和决策过程时，语言模型会不会改变对行动者能动性、心理状态、选择自主性、影响能力与责任的判断。

研究A观察身份标签和过程描述是否对应不同的模型评价。研究B固定机器主体，把过程描述拆成备选方案、理由、反馈和反馈后的行动，分析哪些线索推动评价变化。两项研究分别保存材料、题项、数据和分析结果，使用同一套材料—评分—分析方法。

## 2. 研究计划结构

### 研究A：身份与决策过程归因

研究A交叉六类决策过程与AI/人类身份标签，使用360条DeepSeek API模型模拟问卷响应，观察模型对能动性、体验性、自由意志相关归因与责任的评分变化。研究A已经形成材料、34个情境化题项、聚合数据、条件比较、场景一致性分析、公开图表和复现资产。

独立页面：`/identity-process-attribution-baseline/`

场景一致性分析采用场景×身份×过程条件的96个核心单元，报告条件差异、场景范围、方向一致数和留一场景结果。

### 研究B：机器主体决策过程归因

研究B固定机器主体，从决定信息与反馈后行为的组合中选取六个条件，覆盖八个场景与两个方向，共96条材料。四个主要评价维度为知觉独立性（IN）、目标导向性（GO）、心理状态推断（MSI）和影响能力（IC）；PA5与PA8作为感知能动性的两个补充指标。两个评判模型对同一材料集独立评分。

独立页面：`/machine-decision-process-attribution/`

研究B已经建立材料、评分规则、分析计划和分析界面示例。下一阶段执行双评判模型的正式评分，并在同一框架下更新条件结果、P1—P6与评判模型敏感性分析。

### 未来：跨主体平行测量

先完成研究B的双模型正式评分，再独立建设人类主体题项，记录来源、构念定义和适用范围，与机器主体测量形成平行结构，分析两套测量的题项结构、构念关系和比较方式。

## 3. 从研究A到研究B

研究A提出身份与决策过程如何影响归因的问题，并识别题项来源、构念交叉、文本长度和主体可比性等测量议题。研究B据此固定机器主体，把决定信息、反馈和后续行为拆分为六个可核查条件。研究A观察现象，研究B拆解推动评价变化的线索。

## 4. 两项研究的分工

| 维度 | 研究A：身份与决策过程归因 | 研究B：机器主体决策过程归因 |
|---|---|---|
| 研究任务 | 观察身份与过程描述是否改变评价 | 拆解哪一类线索推动评价变化 |
| 设计 | 六类过程 × 两种身份；八个场景 | 六个条件 × 八场景 × 两方向 |
| 数据 | DeepSeek API模型模拟问卷响应 | 分析界面示例数据与双模型评分协议 |
| 结果用途 | 描述该模型配置在研究A材料中的评价模式 | 呈现机器主体材料、评分、分析和图表链 |
| 测量路线 | 题项结构、构念区分、跨Prompt和跨模型复核 | 原量尺维度、补充指标与跨主体平行测量 |
| 下一步 | 场景一致性分析、Prompt盲化与跨模型运行 | 双评判模型正式评分与结果更新 |
