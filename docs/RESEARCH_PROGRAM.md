# LLM行动者归因评测：研究计划

## 1. 总体研究问题

本项目研究身份标签、决策过程线索与决策后行为，如何影响语言模型对行动者能动性、心理状态、选择自主性、影响能力与责任的判断。项目记录的是模型在给定材料下形成的归因反应。

研究A与研究B承担不同任务。研究A提供广义探索和已有模型输出，研究B提高机器主体测量与行为条件的可控性。两项研究共同构成项目证据链，并分别保存数据和分析结果。

## 2. 研究计划结构

### 研究A：身份与决策过程归因基线

研究A交叉六类决策过程与 AI/人类身份标签，使用已有模型输出观察模型对能动性、体验性、自由意志相关归因与责任的评分变化。它建立探索性基线，并在分析中识别出题项来源、构念交叉、文本长度与主体可比性等测量问题。研究A的已有输出、图表和分析按本研究设计单独保存。

### 研究B：机器主体决策过程归因评测

研究B聚焦机器主体，依次呈现决策信息、反馈与第二次决定，测量 IN、GO、MSI、IC、PA5 和 PA8。设计包含 96 条材料，计划由两个评判模型对同一材料集独立评分。研究B已经完成材料、评分、分析和展示管线；页面当前展示流程演示数据，真实双模型运行完成后将在同一框架下更新结果。

### 共享方法层：归因评测方法与基础设施

共享方法层统一记录材料、题项来源、评分、模型调用、质量检查、分析、展示与复现。研究A与研究B分别调用这些工具，并保存各自的数据契约和分析结果。

### 下一步研究：跨主体平行测量与可比性研究

下一步将独立建设人类主体题项，记录其来源和适用范围，并在跨主体比较前检验机器与人类两套测量之间的可比性。这些准备完成后，项目再开展平行的跨主体比较。

## 3. 从研究A到研究B的演进

研究A先观察身份与过程描述如何影响归因。分析过程中出现了题项来源、构念交叉、文本长度和主体可比性问题。研究B据此聚焦机器主体，并进一步拆分决策信息、反馈和第二次决定。跨主体研究将在独立人类题项和可比性检验完成后展开。

## 4. 现有证据与下一步

| 维度 | 研究A：身份与决策过程归因基线 | 研究B：机器主体决策过程归因评测 |
|---|---|---|
| 研究任务 | 建立身份与过程归因的探索性基线，识别测量问题 | 深化机器主体构念及反馈后行为的测量 |
| 设计 | 六类过程 × AI/人类身份；八个情境 | 六条件 × 八场景 × 两方向；96 条机器主体材料 |
| 已有数据 | 单模型输出、聚合数据、图表与分析产物 | 材料与合成流程演示数据 |
| 当前可回答 | 研究A材料下的描述性比较与关联性诊断 | 材料、评分、分析和展示链是否按协议运行 |
| 测量状态 | 题项来源、构念交叉与主体可比性仍在完善 | 内容效度、构念效度与跨主体可比性列入后续验证 |
| 下一步 | 跨模型与提示稳健性、测量验证、运行溯源补全 | 执行双评判模型运行并更新实证结果 |

研究A已经形成探索性模型输出；研究B完成了材料和分析管线。两项研究各自使用独立的材料、题项和分析结果，模型差异等结论将在真实运行完成后作为评判模型敏感性分析报告。自由意志是项目中的相关归因概念之一，作为 MSI 的探索性题项按单项处理。
