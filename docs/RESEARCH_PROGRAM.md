# LLM行动者归因评测：研究计划

项目稳定ID：`llm_actor_attribution_program`

## 1. 总体研究问题

身份标签、决策过程线索与决策后行为，如何影响语言模型对行动者能动性、心理状态、选择自主性、影响能力与责任的归因判断？

本项目研究的是模型面对给定材料时产生的**归因反应**，不判断 AI 或任何行动者是否真实拥有相应心理属性。

## 2. 研究计划结构

### 研究A：身份与决策过程归因基线

稳定ID：`identity_process_attribution_baseline`

研究A交叉操纵六类决策过程与 AI/人类身份标签，使用已有模型输出探索 agency、experience、自由意志相关归因、责任及其他相关判断。它的功能是建立探索性基线，并暴露题项来源、构念交叉、文本长度与主体可比性等测量问题。

研究A不是被废弃的研究。其已有结果、图表、分析和可核查链继续保留，但由于材料、题项、设计与证据状态不同，不与研究B的统计结果合并。

### 研究B：机器主体决策过程归因评测

稳定ID：`machine_decision_process_attribution`

研究B只研究机器主体，系统呈现决策信息、反馈与第二次决定，测量 IN、GO、MSI、IC、PA5 和 PA8。设计包含 96 条材料，并计划由两个评判模型对同一材料集独立评分。

研究B目前只有 `synthetic_demo` 合成管线数据，用于验证材料、评分、分析与展示链；尚无真实模型实证结果，因此当前不支持效应或模型差异结论。

### 共享方法层：归因评测方法与基础设施

共享方法层组织两项研究可共同复用、但不混合数据的研究链：材料管理、题项来源记录、评分、模型调用、质量检查、分析、展示与复现。共享基础设施服务于一致的证据追踪，不意味着两项研究具有相同设计、相同量尺或可合并结果。

### 研究C候选：跨主体平行测量与可比性研究

研究C候选路线面向机器与人类主体的平行测量。它需要独立开发并记录人类题项，不能通过改写或重贴标签直接把机器题项用于比较；在任何跨主体效应比较前，还需要开展专门的测量可比性研究。该路线当前尚未执行。

## 3. 从研究A到研究B的逻辑演进

探索身份和过程归因
→ 暴露题项来源、构念交叉、文本长度和主体可比性问题
→ 建立机器主体构念与反馈行为的测量深化路线
→ 为未来跨主体平行测量准备基础

这是一条由研究问题和测量缺口推动的逻辑演进，不构成按时间排序的研究优先级，也不表示研究B简单替代研究A。

## 4. 证据状态

| 对照维度 | 研究A：身份与决策过程归因基线 | 研究B：机器主体决策过程归因评测 |
|---|---|---|
| 研究功能 | 建立身份与过程归因的探索性基线，识别测量问题 | 深化机器主体构念及反馈后行为的测量 |
| 设计 | 六类过程 × AI/人类身份；八个情境 | 六条件 × 八场景 × 两方向；仅机器主体；96 条材料 |
| 数据状态 | 有单模型历史输出、聚合数据、图表与分析产物 | 仅有 `synthetic_demo` 合成管线数据 |
| 模型配置 | 单模型历史运行；运行级元数据不完整 | 双评判模型计划；尚无真实运行结果 |
| 测量状态 | 情境化题项池；构念交叉与主体可比性待验证 | 六个构念按各自原量尺评分；内容效度、构念效度与可比性仍待验证 |
| 可支持内容 | 描述已有模型在研究A材料中的归因敏感性与关联性诊断 | 验证材料—评分—分析—展示管线可以贯通 |
| 主要局限 | 单模型、题项来源与构念边界有限、文本长度混淆、运行溯源不完整 | 合成数据不能支持效应、模型差异或理论结论；仅机器主体 |
| 后续任务 | 跨模型与提示稳健性、测量验证、完整运行溯源 | 授权真实运行、质量复核、按预设模型和 P1—P6 报告 |

## 5. 解释边界

- 研究A与研究B的数据和结论不能合并；
- 研究A有历史输出，但证据成熟度有限；
- 研究B的方法约束更严格，但尚无真实模型实证结果；
- 方法成熟度不等于证据完成度；
- 自由意志是总体项目中的相关归因概念之一，不是唯一核心；
- 项目不声称机器和人类测量等值；
- 两项研究均测量模型的归因反应，不据此断言行动者真实拥有相应心理属性。
