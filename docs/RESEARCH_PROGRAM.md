# LLM行动者归因评测：研究计划

## 研究问题

本项目研究语言模型如何根据文本中的身份与决策过程线索理解一个行动者。这里的“行动者归因”指模型在阅读行为描述后，对行动者是否自主、有意图、能够影响结果以及应承担何种责任所作的判断。

项目把三个对象分开：

1. **任务结果**：目标是否完成、约束是否满足；
2. **可观察过程**：是否比较备选、说明理由、处理反馈并改变后续行动；
3. **主体归因**：评价者据此形成的能动性、自由意志、心理状态和责任判断。

## 两项研究

### 研究A：身份与决策过程归因

研究A交叉六类决策过程、AI／人类身份标签和八个场景。六种过程条件与两种身份形成12个实验组合，每个组合包含30次DeepSeek模型问卷评分，共360条记录；记录分布到八个场景后形成96个场景×身份×条件聚合单元。

独立页面：`/identity-process-attribution-baseline/`

主要分析固定报告高结构过程与长文本直接选择的完整写法差异、人类与AI身份标签差异、场景范围、方向一致数和留一场景结果。文本长度与过程条件共同变化，因此不把长度调整系数解释为独立净效应。

### 研究B：机器主体决策过程归因

研究B固定机器主体，把过程线索拆成六种材料条件，覆盖八个场景和两个决定方向，共96条材料。主要评价维度是知觉独立性、目标导向性、心理状态推断与影响能力，并预设六项条件比较。

独立页面：`/machine-decision-process-attribution/`

当前资产包括材料、题项、评分规则、外部记录格式、结构审计和离线分析流程。结构审计覆盖完整性、字段一致、重复和长度阈值；语义对称性、理由强度和反馈强度未纳入当前版本。

## 研究A到研究B的关系

研究A观察身份与成套过程写法对应的评价变化；研究B继续把备选、理由、反馈及反馈后的行动拆开。研究B不是研究A结果的重复展示，而是针对研究A暴露出的解释问题建立更细的材料和分析结构。

## 实践与前沿价值

### 过程监督与推理忠实性

过程监督将评价从最终答案扩展到中间步骤，但可见推理文本仍不能自动视为真实内部过程。本项目通过固定任务结果、改变过程呈现，直接测量“过程文本如何改变评价”，帮助区分过程质量指标和对行动者的心理归因。

### Agent轨迹与反馈后行为

Agent的质量不仅取决于最终成功，还包括工具选择、参数、调用顺序、错误恢复、重复操作、副作用和回退能力。研究B的反馈—维持—改变结构可以映射为轨迹Rubric：系统是否接收反馈、是否更新计划、更新是否进入实际执行，以及执行改变是否合理。

### 产品中的信任和责任

身份名称、解释方式与自动化范围会影响用户接受、复核、覆盖或中止建议。研究A的身份差异和研究B的过程线索提供了可实验操纵的产品变量，可用于考察信任是否与能力匹配，以及成功和失败后的功劳、过错与责任分配。

### 场景化部署与风险治理

同一线索在不同场景中的效果幅度不同，因此评价应与任务风险、人机角色和执行权限一起定义。项目的场景分层、来源记录和材料审计可以作为场景化评测的最小工程骨架。
