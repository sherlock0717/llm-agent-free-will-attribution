# LLM行动者归因评测：研究计划

## 1. 总体研究问题

本项目研究身份标签、决策过程线索与决策后行为如何影响语言模型对行动者能动性、心理状态、选择自主性、影响能力与责任的判断。项目记录模型在给定材料和评分任务中形成的归因反应。

研究A与研究B承担不同任务。研究A建立身份与决策过程归因基线，研究B深化机器主体的决定信息、反馈与第二次决定测量。两项研究分别保存材料、题项、数据和分析结果，共享材料—评分—分析—展示的方法链。

## 2. 研究计划结构

### 研究A：身份与决策过程归因基线

研究A交叉六类决策过程与AI/人类身份标签，使用360条DeepSeek API模型模拟问卷响应，观察模型对能动性、体验性、自由意志相关归因与责任的评分变化。研究A已经形成材料、34个情境化题项、聚合数据、条件比较、场景材料、公开图表和复现资产。

独立页面：`/identity-process-attribution-baseline/`

分析扩展采用场景×身份×过程条件的96个核心单元，报告条件差异、场景范围、方向一致数和留一场景结果。

### 研究B：机器主体决策过程归因评测

研究B固定机器主体，从决定信息D与反馈后行为U的组合中选取六个条件，覆盖八个场景与两个方向，共96条材料。四个主要构念为IN、GO、MSI和IC；PA5与PA8作为感知能动性的两个重叠评分版本。两个评判模型对同一材料集独立评分。

独立页面：`/machine-decision-process-attribution/`

研究B已经完成材料、评分、分析和展示管线。页面展示流程演示数据；下一阶段执行双评判模型运行，并在同一框架下更新条件结果、P1—P6与评判模型敏感性分析。

### 共享方法层：归因评测方法与基础设施

共享方法层统一记录研究问题、材料、题项来源、评分、模型调用、质量检查、分析、页面展示、复现和发布门禁。研究A与研究B分别调用这些工具，并保存各自的数据契约与分析结果。

### 扩展路线：跨主体平行测量与可比性研究

扩展路线将独立建设人类主体题项，记录来源、构念定义和适用范围，再与机器主体测量形成平行结构。重点分析两套测量的题项结构、构念关系和比较方式。

## 3. 从研究A到研究B

研究A提出身份与决策过程如何影响归因的广义问题，并识别题项来源、构念交叉、文本长度和主体可比性等测量议题。研究B据此固定机器主体，把决定信息、反馈和后续行为拆分为六个可核查组合。研究A提供广义基线，研究B深化机器主体一侧的测量。

## 4. 证据组成与扩展路线

| 维度 | 研究A：身份与决策过程归因基线 | 研究B：机器主体决策过程归因评测 |
|---|---|---|
| 研究功能 | 身份与过程归因基线 | 机器主体测量深化 |
| 设计 | 六类过程 × 两种身份；八个场景 | 六个D/U组合 × 八场景 × 两方向 |
| 数据资产 | DeepSeek API模型模拟问卷响应 | 流程演示数据与双模型运行协议 |
| 结果用途 | 描述该模型配置在研究A材料中的归因模式 | 呈现机器主体材料、评分、分析和图表链 |
| 测量路线 | 题项结构、构念区分、跨Prompt和跨模型复核 | 原量尺构念、重叠评分版本与跨主体平行测量 |
| 扩展路线 | 场景级分析、Prompt盲化与跨模型运行 | 双评判模型运行与正式结果更新 |
