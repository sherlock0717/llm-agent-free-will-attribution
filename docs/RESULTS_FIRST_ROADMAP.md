# 结果导向项目路线图

## 最终目标

项目最终需要让读者明确回答五个问题：

1. 身份标签和决策过程写法会怎样改变模型评价？
2. 哪些变化在多个场景中保持相同方向，哪些依赖具体任务？
3. 这些差异是否可能受文本长度、措辞强度等材料因素影响？
4. 结果对Benchmark、Rubric、训练数据质检和Agent评估有什么直接用途？
5. 当前证据不能支持哪些推断？

后续任务必须增强至少一个答案。只增加页面、流程、文件或协议字段的工作不进入近期主线。

## 当前核心结论

- 过程信息会进入模型的能动性判断；
- AI与人类身份标签会改变对相同行为的部分心智和责任评价；
- 多个场景可以呈现共同方向，差异幅度仍依赖任务语境；
- 研究B提供过程线索拆解方法和离线分析设计，不提供新的正式模型结果。

## 已完成的工作

### 研究A：稳健性与限制分析

只使用现有360条记录，已经回答：

- 身份差异是否集中在特定过程条件；
- 哪些场景最推动或抵消总体结果；
- 文本长度、句子数量和理由结构是否与评分共同变化；
- 哪些结论较稳定，哪些需要保留场景或材料限制。

产物：`scripts/analyze_research_a_robustness.py`、`site/data/research_a_robustness_summary.json`、`docs/research_a_robustness_report.md`。文本长度与过程条件共同变化，现有数据不能可靠分离两者的独立作用；相关数值保留在稳健性报告中。

### 研究B：材料确定性结构审计

不产生模型评分，已经检查：

- 六条件×八场景×两方向是否形成完整网格；
- 是否存在重复ID、结构错误或字段不一致；
- 方向版本是否触发预设长度和句子数量阈值；
- 是否存在完全重复正文或高相似材料对。

结果：完整网格96/96，重复ID为0，结构错误为0，字段一致，方向阈值提示为0，完全重复正文为0，高相似材料对为0。语义对称性、理由强度和反馈强度未纳入当前版本，`semantic_review.status` 保持 `not_assessed`。

产物：`scripts/audit_study_b_materials.py`、`research_packages/study_b/material_integrity_audit.csv`、`research_packages/study_b/material_integrity_summary.json`、`docs/reviews/study_b_material_integrity_review.md`。
