研究A · LLM行动者归因评测

同样的行为，写成AI还是人类、有没有理由，会改变模型评价吗？

研究A比较身份标签与六种决策过程写法，观察模型对能动性、心智与责任的评分变化。

八个任务场景分别采用六种过程条件，并将行动者描述为AI或人类。DeepSeek模型阅读材料后完成统一量表，共形成360条评价记录。

查看分析方法

34个题项把模型评价分成几组：决策过程是否完整、行动者是否显得有主见和有能力、是否被赋予自由选择、体验和智能，以及应承担怎样的责任。题项根据既有理论和量表构念改写到具体材料中。

补充统计保留内部一致性、OLS、计划对比、p值、效应量、Bootstrap和场景区组方法。
