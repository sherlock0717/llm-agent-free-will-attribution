# 研究B：机器主体决策过程归因评测

稳定ID：`machine_decision_process_attribution`

研究B属于“LLM行动者归因评测”研究计划，与研究A共享总体问题和方法基础设施，但材料、题项、设计、数据和结论保持独立。

## 研究问题

研究B考察不同决策过程线索与决策后行为，如何影响大语言模型对人工智能决策系统的以下归因判断：

- 知觉独立性（IN）
- 目标导向性（GO）
- 心理状态推断（MSI）
- 影响能力（IC）
- 感知能动性补充指标（PA5、PA8）

## 研究设计

- 仅机器主体；
- 6个条件C0—C5；
- 8个场景；
- 2个方向；
- 96条材料；
- 两个共同主要评判模型配置；
- 每次完整repeat产生192条模型—材料响应。

## 自由意志的位置

- 只对应MSI中的一个探索性题项；
- 不是项目标题；
- 不是唯一核心研究问题；
- 不是独立构念；
- 不生成总分；
- 不用于判断AI是否真实拥有自由意志。

## 数据状态

- 页面公开数据为`synthetic_demo`；
- 只验证材料、评分、分析与展示链；
- 不代表两个评判模型的真实输出；
- 不用于模型排名；
- 不构成理论实证结论。

## 解释边界

- 评分反映评判模型对材料中机器主体的归因反应；
- 不代表机器主体真实具有对应心理属性；
- 研究B不进行AI与人类主体比较；
- 不声称机器与人类测量等值；
- 不声称内容效度或构念效度已经由内部流程确认。

## 与研究A的关系

- 研究A建立身份与决策过程归因的探索性基线；
- 研究B深化机器主体构念与反馈后行为的测量；
- 两项研究的数据、构念与结果不得合并；
- 研究A结果不作为研究B证据，研究B的合成管线也不改写研究A结论。
