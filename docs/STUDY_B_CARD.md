# 研究B：机器主体决策过程归因

研究B固定机器主体，把决策过程拆成可单独检查的文本线索。它关注的不是一个宽泛的“模型是否有能动性”，而是备选方案、明确理由、外部反馈以及反馈后的维持或改变，分别会怎样进入评价过程。

## 研究设计

材料包含六个条件（C0—C5），覆盖八个场景和两个方向，共九十六条材料：

- C0：只给出决定；
- C1：展示备选方案；
- C2：给出明确理由；
- C3：在理由基础上加入外部反馈；
- C4：反馈后维持原决定；
- C5：反馈后改变原决定。

C1与C2是两种并列写法，C3至C5在C2的基础上继续加入反馈和后续行动。

## 评价维度

四个主要评价维度为：

- 知觉独立性（IN）：行动者是否相对独立地形成决定；
- 目标导向性（GO）：行动是否围绕目标组织；
- 心理状态推断（MSI）：行动者是否被赋予思考、意图和意识；
- 影响能力（IC）：行动者是否能够影响决定与结果。

PA5和PA8作为感知能动性的补充指标。自由意志在MSI中保留为探索性单项，不单独承担主要构念结论。

## 当前证据状态

材料、评价规则、离线协议和确定性结构审计完成；语义对称性、理由强度和反馈强度未纳入当前版本。

研究B当前提供：

- 九十六条材料；
- 评价题项与评分规则；
- 六项预设比较P1—P6；
- 外部离线评价记录格式；
- 数据验证、导入和离线分析流程；
- 用于校验统计表、图表和页面组件的固定数据；
- 96条材料的确定性结构审计结果。

确定性结构审计结果：完整网格96/96，重复ID为0，结构错误为0，字段一致，方向长度与句子数量阈值提示为0，完全重复正文为0，高相似材料对为0。`semantic_review.status` 保持 `not_assessed`，已复核材料数为0。

96条材料全部通过确定性结构检查。语义对称性、理由强度和反馈强度未纳入当前版本。

固定数据不构成正式模型结果。研究B页面用于展示材料结构、评价维度和分析方法，不设置主要研究发现。

## 实践用途

研究B可以直接转化为评测与数据生产方法：

- 把“会推理”拆成列出备选、说明标准和给出理由；
- 把“能接受反馈”拆成识别反馈、判断相关性和调整行动；
- 将反馈后的维持与改变分别评价；
- 每项预设比较对应明确的信息增量；
- 区分对行动者的心理归因与真实任务表现。

材料审计与语义复核分开处理：确定性结构检查覆盖网格完整性、字段一致性、重复和阈值提示；语义对称性、理由强度和反馈强度属于独立工作，未纳入当前版本。
