# 评测设计检查清单

本清单把研究A的已有结果与研究B的材料设计转化为可直接使用的检查项，用于Benchmark与Rubric设计、数据生产与质检，以及Agent评估。清单只保留一个入口，不复制到每个页面。

## 一、Benchmark与Rubric

- [ ] 身份、过程、结果是否分开控制？
- [ ] 备选、理由、反馈、行动是否原子化为可单独核查的变量？
- [ ] 是否覆盖多个场景，而不是单一任务？
- [ ] 同一能力点是否有等价的多种表述？
- [ ] 是否报告结果在不同场景中的范围，而不是只报总体均值？
- [ ] 是否区分“对行动者的归因”与“任务能力本身”？

## 二、数据生产与质检

- [ ] 新增文本是否提供真实的决策信息，而不是只增加解释性文字？
- [ ] 给出的理由是否对应目标，而不是无关铺陈？
- [ ] 反馈是否落实到具体的后续行动？
- [ ] 条件之间的文本长度是否可比，避免长度混杂？
- [ ] 是否存在条件标签或场景标识泄漏进正文？
- [ ] 语义不确定项是否记录为人工复核，而不是直接判对或判错？

## 三、Agent评估

- [ ] 是否发现并比较了备选方案？
- [ ] 是否说明了选择标准？
- [ ] 是否保留了任务约束？
- [ ] 是否处理了外部反馈？
- [ ] 是否根据反馈更新了计划？
- [ ] 更新是否真正影响了后续执行，而不是复述？
- [ ] 是否把任务结果与归因评分分别报告？

## 依据

- 研究A（现有结果）：过程写法进入能动性评价、身份标签改变心智与责任评价、结论方向跨场景重复但幅度依赖场景。见 `docs/research_a_robustness_report.md`。
- 研究B（材料设计与审计）：每个条件只改变一个目标信息单元、方向版本长度可比、材料审计先于评价分析。见 `docs/reviews/study_b_material_integrity_review.md`。
